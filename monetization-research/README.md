# 個人開発で収益化：プラットフォーム比較とアイデア評価

調査日: 2026-11-22
目標: **年間利益 1,000万円以上**（月あたり約83万円）。「1000」を1000万円と解釈しています。違う意味なら教えてください。

---

## 0. 結論

| | 結論 |
|---|---|
| どこで作るか | **Web + LINE通知で始め、手応えが出たらスマホアプリ**。Steamは「どうしてもゲームを作りたい」場合だけにする |
| 一番の候補 | **旅行（航空券の安い時期×リマインド）**。課金の手段（アフィリエイト＋サブスク）がはっきりしていて、SEOでも集客できる |
| 友達リマインダー | 仕組みは面白いが、**単体ではお金にしにくい**。旅行アプリの「一緒に行く友達を誘う」機能として組み込むのが一番強い |
| 合体案 | **「友達と旅行を実現させるエージェント」**：お互いに「行きたい」が一致したときだけ通知し、安い時期と価格を提案し、予約で収益化する |

## 1. プラットフォーム別の比較

### 1-1. Steam（PCゲーム）

| 項目 | 内容 |
|---|---|
| 手数料 | 売上の30%（一定額を超えると25%→20%）。1作品ごとに登録料$100 |
| 売上の分布 | **極端に偏る**。2025年にSteamで出た作品の売上中央値は約$249という推計がある。累計で見ても、中央値は数千〜1.5万ドル程度 |
| 成功している層 | 2025年に$10万以上を売り上げた作品は5,863本（Valve発表）。リリース数全体のごく一部 |
| 日本の個人開発 | 『Öoo』『Chill with You』『DRAPLINE』などのヒットはあるが、作者たちも「予想外の成功」と話している。その一方で「100本も売れない」という報告もある |
| 収益の形 | 基本は売り切り。DLCや続編を出さないと、収入が継続しない |
| 必要なスキル | プログラミングに加えて、絵・音・ゲームデザイン・トレーラー。開発期間は1〜3年が普通 |
| 向いている人 | ゲーム作りそのものが好きで、宝くじ的なリスクを受け入れられる人 |

**評価**: 1000万円に届く確率は低い（上位数%の世界）。ただ、当たれば一作で到達することもある。継続収益を狙うには向かない。

### 1-2. Web（Webサービス・SaaS・メディア）

| 項目 | 内容 |
|---|---|
| 手数料 | 決済手数料のみ（Stripeで約3.6%）。ストアの審査もない |
| 集客 | SEO・SNS・口コミ。**検索ボリュームのあるテーマ（例：「沖縄 安い時期」）なら自動で集客できる** |
| 収益化 | アフィリエイト・広告・サブスク・買い切りを組み合わせられる |
| 売上の分布 | Indie Hackers系のデータでは、約半数がMRR（月の継続収益）$1K未満。ARR（年の継続収益）$10万を超えるのは2〜5%程度（ただし自己申告のデータ） |
| 開発速度 | 最速。すぐ公開して、毎日改善できる |
| 弱点 | プッシュ通知が弱い → **リマインド系なら、LINE公式アカウントやメールで補える** |

**評価**: 検証コストが最も低い。データ型のサービスならSEOで資産が積み上がる。最初の一手として最適。

### 1-3. スマホアプリ

| 項目 | 内容 |
|---|---|
| 手数料 | 年間収益$100万以下ならApple・Googleとも15%（Small Business Program） |
| 売上の分布 | RevenueCatのデータでは、**公開から1年後の月収中央値は$50未満**。$1万に届くアプリは約3.5% |
| 強み | プッシュ通知、ウィジェット、カレンダー連携。**リマインド系とは非常に相性が良い**。サブスクも受け入れられやすい |
| 弱点 | ストア内の検索だけでは集客しにくく、広告費がかかりやすい。審査もある。iOSとAndroidの両方が必要（Flutter / React Nativeで緩和できる） |
| AIアプリ | インストールあたりの収益は平均の約2倍という報告がある。一方でAPI原価がかかる |

**評価**: リマインド・習慣化系には最適な形。ただ、需要を確かめる前に作るとコストが高い。Webで需要を確かめてから移行するのがおすすめ。

### 1-4. まとめ表

| | Steam | Web | スマホ |
|---|---|---|---|
| 初期コスト | 高い（1〜3年） | **低い（数週間）** | 中くらい（数か月） |
| 収益の継続性 | 低い（売り切り） | **高い（サブスク・SEO資産）** | 高い（サブスク） |
| 集客 | Steamのウィッシュリスト | **SEO** | 広告・SNS |
| 通知 | ― | △（LINEで補える） | **◎** |
| 1000万円に届く確率 | 低い・一発型 | 中くらい | 中くらい |

## 2. アイデア評価

### 2-1. 航空券の時期別価格 × 旅行リマインダー

**最大の壁は「データをどう取るか」**

| 取得方法 | 状況 |
|---|---|
| Amadeus Self-Service API | **2026年7月17日に提供終了**。個人開発者は使えなくなった |
| Google Flightsのスクレイピング | 利用規約違反。ブロックされやすく、続けられない |
| Travelpayouts Data API | キャッシュされた価格・価格推移が取れる。**アフィリエイトとセットで、個人でも使える**。リアルタイムではない |
| Duffel | 検索から予約まで。従量課金で、すぐ登録できる。予約まで自社でやるなら選択肢になる |
| Skyscanner / Kiwi | パートナー審査制・招待制で、個人にはハードルが高い |
| LCCのセール情報（Peach・Jetstar・ZIPAIRなど） | 公式サイト・メルマガ・SNSから集めて手作業で整理できる。「セール周期の傾向」自体が価値のあるコンテンツになる |

→ **Travelpayoutsで価格推移を取り、LCCのセール情報を独自に蓄積する**のが現実的です。データを自分で蓄積していくこと自体が、他社がすぐに真似できない強みになります。

**競合**: Google Flights（無料で価格追跡できる）、Hopper（価格予測）、Going（セール情報を有料で配信）、Skyscanner。
→ 「価格を追跡する」だけでは勝てません。**差別化の軸は「旅行に行かせる」こと**です。
- 日本の祝日・連休カレンダーから「次の3連休は○日。今が買い時」と提案する
- 「有給を1日足すと5連休」になる最適日を提案する
- 「去年この時期に行ったところ」「行きたいリスト」を定期的にリマインドする
- 締切を作る：「この価格帯は残り○日で終わる傾向」

**収益の計算（1000万円に必要な量）**

| 収益源 | 単価の目安 | 1000万円に必要な量 |
|---|---|---|
| 航空券アフィリエイト（予約額の約1.1〜1.5%） | 3万円の予約で約400円 | 年約2.5万件 → 割に合わない |
| ホテルアフィリエイト（約4〜5%） | 4万円の予約で約1,800円 | 年約5,500件 |
| サブスク（月480円） | 手数料を引いて約400円 | **常時約2,100人** |
| 組み合わせ（例） | サブスク1,000人＋ホテル3,000件＋広告 | 届く範囲 |

→ **航空券のアフィリエイトだけでは無理**です。ホテル・パッケージツアーへ誘導することと、サブスクで「先取りアラート・有給最適化・無制限ウォッチ」を売ることが重要になります。

**SEOの勝ち筋**: 「沖縄 航空券 安い時期」「札幌 何月が安い」のようなページを、蓄積したデータで路線ごとに自動生成します。これは検索ボリュームの大きいキーワード群です。

### 2-2. 友達と遊ぶリマインダー（エージェントがこっそり誘う）

**核になる仕組み** = 「お互いに相手に知られずに『会いたい』を表明し、**両方が一致したときだけ**エージェントが自然に提案する」
→ 断られる怖さをなくせる。マッチングアプリの「相互いいね」を友達関係に応用した形で、心理的に強いニーズがあります。

**類似サービス（2025〜2026年）**
- Digipals（YC 2025年秋）：各ユーザーにAIエージェントがつき、カレンダー・位置情報・関係の履歴から会う機会を増やす
- Alfi（YC）：AIが参加するグループチャット。予定を覚えてくれる
- Sidekix：友達をグループ化し、AIが日程を調整する
→ **海外ではYCが投資するレベルで注目されている領域**。日本向け（LINE文化）はまだ空いている可能性があります。

**課題**
1. **ネットワーク効果の壁**：両方が使っていないと成立しない → **LINE Botにして、グループに招待するだけで始められるようにする**のが必須
2. **収益化が難しい**：友達同士のアプリに課金する人は少ない。マネタイズの手段は飲食店予約（ホットペッパー等）・イベントチケットのアフィリエイトくらい
3. **信頼性**：「AIに勝手に誘われていた」と知ったときに嫌がられるリスクがある → 「一致したときだけ」「本人がオプトイン済み」を明示する設計が重要
4. **「お互いが持っている話題」**：会話内容を解析するのはプライバシー的に重い → 本人が登録した「興味タグ」の共通点を出す程度に留めるのが安全

**評価**: グロース（拡散）のエンジンとしては強いが、単体で1000万円は難しい。

### 2-3. 合体案（推奨）：「友達と旅行を実現させるエージェント」

```
① 各自がこっそり「○○と旅行行きたい」「沖縄行きたい」を登録
② お互い一致したらエージェントが通知（LINE）
   「AさんとBさん、2人とも温泉に行きたいみたい。3月の3連休、羽田→福岡が今 往復1.8万円です」
③ 日程調整 → 航空券・ホテル予約リンク（アフィリエイト）
④ 行くまでリマインド、行った後は「次どこ行く？」
```

- 友達リマインダーの「拡散力」と、旅行の「収益性」を組み合わせられる
- 旅行は1件あたりの単価が高い（ホテル＋航空券で数千円の報酬もありうる）
- 「旅行はリマインドされないと行かない」というあなたの課題感にそのまま応えられる

## 3. 進め方（ロードマップ案）

| 期間 | やること | 判断基準 |
|---|---|---|
| 1〜2週 | **SEOページ＋価格推移のデモ**（Next.js＋Travelpayouts）。主要20路線の「何月が安いか」ページ | ページを公開して、インデックスされるか |
| 3〜6週 | **LINE Bot**：路線・時期をウォッチ → 安くなったら通知＋連休リマインド | 登録者100人／アフィリエイト経由のクリック数 |
| 2〜3か月 | 「友達と一致したら通知」機能を追加（LINEグループ招待で拡散） | 招待率、一致から予約に進む率 |
| 4〜6か月 | 有料プラン（月480円前後）：無制限ウォッチ・有給最適化・先取りアラート | 課金率2〜5% |
| 6か月〜 | 手応えがあればスマホアプリ化（ウィジェット・プッシュ通知） | 月30万円 → 月83万円を目指す |

**技術スタック案**: Next.js（Vercel）＋ Supabase ＋ LINE Messaging API ＋ Travelpayouts API ＋ Claude API（提案文の生成）。月の固定費は数千円から始められます。

## 4. 「その他も考えてる」アイデアの評価基準

他のアイデアは、次の5点でスコアを付けると比較しやすいです。

1. **検索されるか**（SEOで無料集客できるか）
2. **お金が動く場面に近いか**（予約・購入・仕事の効率化）
3. **データやAIで差別化できるか**（真似されにくいか）
4. **一人で作れる規模か**（MVPを1か月以内に出せるか）
5. **継続課金の理由があるか**（毎月使う必然性があるか）

旅行アイデアは 1・2・3・5 が強く、友達リマインダーは 3・5 は強いが 1・2 が弱い、という評価になります。
